# 学习通粘贴限制解锁

解锁超星学习通（`*.chaoxing.com`）作业页面中的粘贴限制，覆盖代码编辑区和富文本编辑器。

## 适用场景

| 编辑器 | 出现位置 | 支持情况 |
|---|---|---|
| CodeMirror 5 | 编程题代码框 | ✅ |
| CodeMirror 6 | 新版编程题代码框 | ✅ |
| UEditor | 主观题富文本作答框 | ✅ |
| 普通输入框 / 讨论区 | 回复、填空 | ✅ |

## 特性

- **保留原生粘贴**：图片与附件不接管，仍走平台自带的上传链路，不会出现"看起来插进去了、刷新就没了"
- **多行代码不粘连**：粘贴网页复制的多行文本时按编辑器规则还原换行，不会挤成一行
- **插入位置准确**：聚焦顺序变化、点击工具栏后再粘贴，内容仍落在原来的光标处
- **页面能感知修改**：插入后同步编辑器状态，不会出现"离开页面提示可能未保存"
- **不越权**：只解除粘贴开关，不修改任何身份或权限字段
- **考试域默认排除**：`exam.chaoxing.com` 不生效，需要可自行删掉 `@exclude`

## 安装

1. 安装 [ScriptCat](https://scriptcat.org/) / [Tampermonkey](https://www.tampermonkey.net/) / [Violentmonkey](https://violentmonkey.github.io/)
2. 打开 `1.4.0_xxt.js`，脚本管理器会接管安装
3. 刷新学习通页面

## 使用

安装后无需任何操作，直接在作业页面粘贴即可。

## 兼容性

- 需要脚本管理器支持 `@grant unsafeWindow`
- 只在本站域名生效，不影响其它网站
- 同源 iframe 自动处理；跨域 iframe 无法访问（浏览器限制）
